🌸 Astheric Bot

WhatsApp bot yang cantik dan interaktif, dibangun menggunakan Node.js dan Baileys.

✨ Fitur

Menu Interaktif dengan Button
Manajemen Grup (Antilink, Welcome, etc.)
Sistem Pendaftaran User
Manajemen Admin & Owner
Dan masih banyak lagi!
🚀 Cara Setup

Clone Repository
git clone https://github.com/username/astheric-bot.gitcd astheric-bot
Install Dependencies
npm install
Konfigurasi Variabel Lingkungan
Salin file .env.example ke .env (atau buat file .env baru).
Isi nilai yang diperlukan seperti OWNER_NUMBER dan MONGO_DB_URI.
Jalankan Bot
npm start
